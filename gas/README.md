# 問い合わせメール自動集計スクリプト（AI解析付き）

Gmail に届いた問い合わせメールを Claude AI で解析し、Google スプレッドシートへ自動転記するツールです。

## できること

- 指定 Gmail ラベルの新着メールを5分おきに自動検知
- **Claude AI がメール本文を解析して構造化情報を抽出**
  - 会社名・氏名・電話番号
  - 問い合わせ種別（製品問い合わせ・見積もり依頼・クレームなど）
  - 問い合わせ内容の要約（100文字以内）
  - 緊急度（高・中・通常）
- 緊急度に応じてスプレッドシートの行を色分け（高=赤, 中=黄）
- ステータス（未対応 / 対応中 / 完了 / 保留）をプルダウンで管理
- 重複登録を自動防止

## セットアップ手順

### 1. Gemini API キーを取得する

[Google AI Studio](https://aistudio.google.com/app/apikey) で API キーを取得してください（Google アカウントがあれば無料で利用できます）。

### 2. Gmail ラベルを作成する

Gmail で問い合わせメールに付けるラベルを作成してください（例: `問い合わせ`）。  
フィルタを設定しておくと自動でラベルが付きます。

### 3. Google スプレッドシートを作成する

集計先のスプレッドシートを新規作成し、URL のスプレッドシートIDをメモしてください。

```
https://docs.google.com/spreadsheets/d/【ここがID】/edit
```

### 4. Google Apps Script を設定する

1. [script.google.com](https://script.google.com) を開く
2. 「新しいプロジェクト」を作成
3. `inquiry_to_sheet.js` の内容を貼り付ける
4. ファイル冒頭の `CONFIG` を編集する

```js
const CONFIG = {
  SPREADSHEET_ID: 'YOUR_SPREADSHEET_ID', // ← スプレッドシートIDに変更
  LABEL_NAME: '問い合わせ',               // ← Gmail のラベル名に変更
  SHEET_NAME: '問い合わせ一覧',
  EXTRA_QUERY: '',
  GEMINI_MODEL: 'gemini-2.0-flash',           // 高速・低コストモデル
};
```

### 5. API キーをスクリプトプロパティに設定する

Apps Script エディタで：  
**プロジェクトの設定（歯車アイコン）→ スクリプトプロパティ → プロパティを追加**

| プロパティ名 | 値 |
|------------|-----|
| `GEMINI_API_KEY` | `AIza...`（取得したAPIキー） |

> ⚠️ APIキーはスクリプト内に直書きせず、必ずスクリプトプロパティに設定してください。

### 6. 初回セットアップを実行する

Apps Script エディタで `setup` 関数を選択して実行してください。  
権限の承認ダイアログが表示されるので「許可」を選択します。

## スプレッドシートの列構成

| 列 | 内容 | 入力方式 |
|----|------|---------|
| A | 受信日時 | 自動 |
| B | 件名 | 自動 |
| C | 差出人名 | 自動 |
| D | 差出人メールアドレス | 自動 |
| E | **会社名** | AI解析 |
| F | **氏名** | AI解析 |
| G | **電話番号** | AI解析 |
| H | **問い合わせ種別** | AI解析 |
| I | **問い合わせ内容（AI要約）** | AI解析 |
| J | **緊急度** | AI解析 |
| K | 本文（原文冒頭） | 自動 |
| L | スレッドID | 自動 |
| M | ステータス | プルダウン選択 |
| N | 担当者 | 手動入力 |
| O | 対応メモ | 手動入力 |

## コスト目安

`gemini-2.0-flash` 使用時：  
無料枠（1分あたり15リクエスト、1日1500リクエスト）内であれば **無料**。  
超過した場合もメール1件あたり約 **0.0001ドル以下** と非常に低コストです。

## カスタマイズ

問い合わせ種別の分類やAI解析の項目は `_analyzeWithClaude` 関数内のプロンプトを編集することで変更できます。
